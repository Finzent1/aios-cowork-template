# Prime

> Run this at the start of every session to load full context.

## Steps

1. Read `CLAUDE.md`
2. Read all files in `context/` — `firm.md`, `deals.md`, `strategy.md`
3. Read `gtd/dashboard.md`

## Summary

After reading, provide:

1. **Who I am and what we do** — one sentence confirmation
2. **Active deals** — name, status, and what's happening right now on each
3. **Priorities** — revenue target progress (if populated), current strategic focus
4. **GTD state** — flagged/urgent items, next actions count, anything in the waiting-for list that needs attention
5. **Confirmation** you're ready to work

Keep the summary concise. Surface what matters; don't repeat everything back verbatim.
